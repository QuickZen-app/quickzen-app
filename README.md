Se abre la app, se escribe, y no hay nada más que decidir. Sin diálogo de
"nuevo archivo", sin botón "Guardar", sin menús pesados — todo se guarda
solo en un buffer temporal mientras se escribe.

- Buffer efímero autoguardado, con expiración configurable
- Resaltado de Markdown en vivo (encabezados, negrita, cursiva, código)
- Personalización completamente libre: color, tipografía, layout y sonido,
  sin presets fijos
- Modo enfoque total y modo línea actual
- Exportar a Markdown, texto plano o HTML
- 100% gratis, sin ninguna función bloqueada — el proyecto es de código
  abierto y las donaciones son opcionales, no cambian nada dentro de la app

`Python` `GTK4` `Libadwaita`
